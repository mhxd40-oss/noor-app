# نور — القرآن والسنة

تطبيق ويب إسلامي (PWA) يشمل:
- القرآن الكريم بروايتي حفص عن عاصم وورش عن نافع (المصدر: Quranpedia.net)
- التفسير (Quranpedia.net، مع الرجوع للتفسير الميسر عبر alquran.cloud عند عدم توفره)
- الأحاديث النبوية مع أحكام المحدّثين عليها (المصدر: الموسوعة الحديثية — دُرر السنية)
- تلاوة صوتية لثلاثة قراء (محمد اللحيدان، ياسر الدوسري، سعد الغامدي — عبر mp3quran.net)
- مواقيت الصلاة (Aladhan API)

## التشغيل محليًا / النشر

هذا تطبيق ثابت بالكامل (Static) — لا يحتاج خادمًا خلفيًا أو قاعدة بيانات، فقط استضافة ملفات ثابتة عبر HTTPS (GitHub Pages، Netlify، Vercel، أو غيرها). لتفعيل خاصية "تثبيت التطبيق" (PWA) لا بد أن يكون مستضافًا على HTTPS — لن تعمل هذه الخاصية عند فتح الملف مباشرة من الجهاز (file://).

### النشر عبر GitHub Pages
1. ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub.
2. من إعدادات المستودع (Settings → Pages)، فعّل GitHub Pages واختر الفرع (main) والمجلد الجذر (/).
3. بعد دقائق، سيكون التطبيق متاحًا على رابط مثل: `https://<username>.github.io/<repo-name>/`
4. من جوال (كروم/سفاري)، افتح الرابط → قائمة الخيارات → "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق".

## هيكل الملفات
```
index.html       الملف الرئيسي (كل التطبيق: HTML + CSS + JS)
manifest.json    بيانات التطبيق (الاسم، الأيقونات، الألوان) لخاصية PWA
sw.js            Service Worker بسيط (لتفعيل التثبيت فقط، بدون تخزين مؤقت للعمل بلا إنترنت)
icons/           أيقونات التطبيق بأحجام مختلفة
```

## المساهمة
هذا مشروع مفتوح للتعديل من الجميع. أي تحسين أو إصلاح خطأ أو ميزة جديدة — رحّب به عبر Pull Request.

## المصادر المستخدمة
جميع بيانات القرآن والحديث تُجلب حيًّا من مصادرها في كل مرة (لا توجد نسخة مخزّنة داخل الكود)، لضمان الدقة وتفادي أي خطأ في النقل.
